# Pizza Sales Performance Analysis | Power BI
## Project Overview
This project is an interactive **Pizza Sales Performance Dashboard** developed using **Microsoft Power BI**.
The data was stored in a **PostgreSQL database** and connected directly to Power BI for data analysis, modeling, and visualization.
The dashboard provides insights into sales performance, revenue trends, ordering patterns, pizza categories, pizza sizes, and individual pizza performance.
## Tools & Technologies
- PostgreSQL
- pgAdmin 4
- Microsoft Power BI
- Power Query
- DAX
- SQL

## Project Objectives
- Analyze overall pizza sales performance
- Monitor total revenue and total orders
- Identify top-performing pizzas
- Identify low-performing pizzas
- Analyze monthly revenue trends
- Analyze sales by pizza category
- Analyze sales by pizza size
- Understand ordering patterns by day of the week
- Compare pizza quantity sold across different sizes and categories
